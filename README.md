# Marine Engineer Reviewer — Testable PWA

## Run on a computer
1. Extract this ZIP.
2. Make sure Python 3 is installed.
3. Open a terminal in this folder.
4. Run:
   python run_test_server.py
5. Open http://localhost:8000/ if it does not open automatically.

A PWA must be served over HTTP/HTTPS for service-worker and install features; opening index.html directly with file:// is not sufficient.

## Test on iPhone/Android
For a phone, localhost on the computer is not the same as the phone. Publish the folder to an HTTPS host such as GitHub Pages, Netlify, Vercel, or your own HTTPS web server, then open the HTTPS address on the phone and use Add to Home Screen/Install.

## Included
- PWA manifest
- Service worker/offline cache
- Install prompt where supported
- Mobile-first UI
- 42 original practice questions
- Function 1 / Function 2 / Function 3 / OIC-EW filters
- 20-question mock mode
- Immediate explanations and references
- Local progress and accuracy
- No external libraries or runtime CDN dependency

## Source positioning
This is an independent reviewer. It uses MARINA-published competency/syllabus material as the subject framework. It is not an official MARINA app and does not copy or claim access to official examination questions.
